# LinkHer web branding

Current public name: **LinkHer**.

Positioning: a women's safety site with trusted contacts, check-ins, and community support. Dating safety is one use case, not the site's overall identity.

Use `/brand-logo.png` for the public logo. This asset is the existing standalone LinkHer artwork, without the SafeTea cup. The filename intentionally stays neutral for a future rename.

When renaming, update public page titles, metadata, visible text, share labels, subscription labels, and the PWA manifest where present. Retain legal operator names and existing domains, support email addresses, API paths, localStorage keys, and native app IDs unless separately migrating them. Those identify existing accounts and integrations.
